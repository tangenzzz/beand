# Map data

`land.json` (coastlines between 38° N and 38° S) and `borders.json`
(country outlines touching the tropics, by ISO code) are cut from
Natural Earth 1:110m `ne_110m_land` and `ne_110m_admin_0_countries`
(https://www.naturalearthdata.com), which is in the public domain.
Used by the coffee map in Settings → Statistics → Beans.
